QuorumRAG Local-First P2P Agentic RAG
=====================================

Installed Location:
  C:\Program Files\QuorumRAG\quorumrag.exe
  C:\Program Files\QuorumRAG\quorumrag-launch.cmd

Zero-Touch Environment Guarantee:
  This installer never modifies User or System PATH registry variables.
  Launch QuorumRAG from the Start Menu ("QuorumRAG Chat UI"), Desktop shortcut,
  or directly via C:\Program Files\QuorumRAG\quorumrag-launch.cmd.

Optional Background Service:
  An on-demand Windows Service ("QuorumRAGDaemon") is registered with Manual startup.
  To start it in the background as an administrator:
    sc.exe start QuorumRAGDaemon
  To stop it:
    sc.exe stop QuorumRAGDaemon

Default Web UI:
  http://127.0.0.1:3031
